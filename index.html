Project 01

WoodCraft Vision

A practical smart eyewear designed for woodworking professionals, addressing the two primary causes of workshop accidents: improper tool use and lack of real-time safety feedback.

The device lifts the antenna to 50–100m height using helium balloons, achieving wide-area coverage at low deployment cost.

Category

Industrial Design · Personal Work

Core Technology

  • LiDAR for precise distance measurement
  • AI-powered tool recommendations
  • Real-time safety analytics
  • Eye tracking technique
  • Auto-tinting visor
  • Cameras + rangefinding + AI detection

Key Features

  • Accurate cutting distance measurement
  • Instant hazard alerts overlay
  • Air-permeable cushioned frame
  • Touch adjustment controls
  • Companion mobile app
  • Teaching & community modes

Design Language

  • White frame — clean, professional
  • Orange accents — safety visibility
  • Adjustable headband + buckle
  • High-strength visor housing

Research Findings

  • Accidents from improper tool use
  • Existing goggles lack smart alerts
  • VR headsets too heavy for workshops
  • Need for pre-use safety training
Project 02

Balloon Comm

A tethered balloon communication restoration system designed for post-earthquake disaster zones. Deployed by airdrop, it uses a master-subordinate balloon network to rapidly restore LTE and GSM coverage.

Each balloon group covers 30km diameter, serving 30,000–50,000 people, ensuring short-term communication until infrastructure is rebuilt.

Category

Systems Design · Hardware · Personal Work

System Components

  • Master balloon with LTE base station
  • Subordinate balloons (GSM backup)
  • Microwave antenna mesh network
  • Radar / camera equipment
  • Satellite antenna link
  • Mesh router + power system

Technical Specs

  • Antenna elevation: 50–100m
  • Coverage: 30km diameter
  • LTE: 700MHz–2.7GHz, 15km range
  • GSM: 900/1800MHz, 35km range
  • Wind tolerance: up to 15m/s safely
  • 3 directional antennas × 60° per balloon

Deployment

  • Airdrop from aircraft
  • Open case → inflate balloon
  • Release line → check signal
  • Fully operable by rescue teams
  • Recovery via reel-in system

Testing Results

  • Open environment: 2km stable range
  • Building occlusion: 1km stable
  • Prototype validated via actual launch
  • ATK-LORA-01 module tested
  • Fluid simulation at 10/15/20 m/s
